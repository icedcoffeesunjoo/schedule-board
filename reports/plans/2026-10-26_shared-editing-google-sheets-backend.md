# Status: DONE — 지도학생 공유 편집 (Google Sheets + Apps Script 백엔드)

## Objective
지금은 데이터가 각자 브라우저의 localStorage에만 저장된다. 이것을 Google Sheets와 Apps Script 웹앱으로 만든 공용 저장소로 옮긴다. 그러면 GitHub Pages 링크로 접속한 지도학생 누구나 같은 데이터를 보고, 연구실 공용 비밀번호를 아는 사람은 일정과 담당자를 입력하거나 삭제할 수 있다.
- 보기는 링크만 있으면 된다. 쓰기는 서버에서 비밀번호를 확인한다. 다른 사람의 변경은 20초마다 폴링하고, 탭으로 돌아올 때도 반영한다.
- 작업 단위 API를 쓰고 `LockService`로 잠그며, ID는 서버가 발급한다. 그래서 동시 편집에도 데이터가 유실되지 않는다.
- `config.js`의 `apiUrl`이 비어 있으면 기존 localStorage 모드로 동작한다.

진행 중 사용자 추가 요청(모두 반영):
- 담당자별로 묶은 월별 간트. 공유 시트는 빈 상태로 시작한다.
- 일정 메모: 등록 폼, 현황표 ✏️ 편집 창, 막대 📝/툴팁. 메모 칸 스타일을 다크 테마로 통일.
- 구분 정리: 인재개발·행정기획·대외협력·연구윤리 삭제. 프로포절 발표, 요지 발표, 랩미팅 발표, 논자시, IRB 제출, 논문 투고, 학회 참석, 졸업 계획 추가. 예시 데이터를 대학원 일정으로 교체.
- 기준일: 고정값 10/25 대신 실제 오늘 날짜를 쓴다(오늘 = 2026-10-26).
- 간트: 오늘이 속한 달부터 2029.02까지, 위·아래 2단으로 나눔.
- 상세 현황표: 연구원별 묶음과 연도별 탭.
- 담당자 정렬: 박사수료 → 박사과정 → 석박통합과정수료 → 석사수료 → 석사과정, 같은 과정 안에서는 가나다순. 담당자를 추가할 때 과정을 고르는 선택칸 추가.
