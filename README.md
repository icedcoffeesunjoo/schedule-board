# 연구실 일정 편성표 (Schedule Board)

지도학생들의 프로포절·요지 발표, 랩미팅 발표, 논자시, IRB 제출, 논문 투고, 학회 참석, 졸업 계획 같은 일정을 **월별 간트 타임라인**에서 한눈에 보는 웹 앱입니다. 같은 담당자의 일정이 겹치거나 마감이 다가오면 자동으로 알려줍니다.
링크 하나로 지도학생 모두가 **같은 일정표를 함께 입력·수정·삭제**할 수 있습니다(공유 모드).

---

## 🌟 주요 기능

1. **간트 타임라인 (이번 달 ~ 2029.02 · 월별, 위·아래 2단)**
   * 기간 전체를 위·아래 두 단으로 나눠 표시합니다(예: 2026.10~2027.12 / 2028.01~2029.02). 두 단에 걸친 일정은 양쪽에 `◀ ▶` 표시와 함께 나옵니다.
   * 담당자(연구원)별로 묶고, 각 묶음 안에서는 시작일 순으로 정렬합니다.
   * 접속한 날짜를 기준으로 '오늘' 기준선이 그어집니다.

2. **일정 상세 현황표: 연구원별 묶음 + 연도별 탭**
   * `전체 / 2026년 / 2027년 / …` 탭으로 연도별로 볼 수 있습니다. 여러 해에 걸친 일정은 해당하는 모든 연도 탭에 나옵니다.

3. **📝 메모**
   * 일정을 등록할 때 메모를 함께 쓸 수 있고, 현황표의 ✏️ 버튼으로 나중에 수정할 수 있습니다.
   * 메모가 있는 막대에는 📝 표시가 붙고, 마우스를 올리면 내용이 보입니다.

4. **👥 담당자 관리**
   * 이름과 과정(박사수료 / 박사과정 / 석박통합과정수료 / 석사수료 / 석사과정)을 골라 등록합니다. 담당자는 `홍길동 (석사과정)` 형식으로 저장됩니다.
   * 담당자 목록은 위의 과정 순서로, 같은 과정 안에서는 가나다순으로 정렬됩니다.

5. **충돌·마감 임박 자동 감지**
   * 같은 담당자의 일정 기간이 겹치면 경고 배너와 주황색 막대로 알려줍니다.
   * 오늘부터 D-3 이내에 마감하는 미완료 일정은 붉은색으로 강조합니다.

6. **백업 / 인쇄**
   * `.json` 내보내기·불러오기, 인쇄 / PDF 출력을 지원합니다.

## 🔗 지도학생과 공유하기 (공유 모드 설정 · 최초 1회)

데이터는 **교수님의 구글 시트**에 저장됩니다. 학생들은 로그인 없이 링크로 접속해 일정을 보고, **연구실 공용 비밀번호**를 아는 사람만 입력·수정·삭제할 수 있습니다.

### 1) 구글 시트 + Apps Script 만들기
1. [Google Sheets](https://sheets.google.com)에서 빈 스프레드시트를 새로 만듭니다(이름 예: `연구실 일정표 DB`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣은 뒤 저장(💾)합니다.

### 2) 편집 비밀번호 설정
1. Apps Script 왼쪽 메뉴 **⚙️ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**를 누릅니다.
2. 속성 `EDIT_PASSWORD`, 값에 연구실 공용 비밀번호(예: `lab2026!`)를 넣고 저장합니다.
   * 비밀번호는 이 속성에서 언제든 바꿀 수 있습니다. 바꾸면 학생들은 다음에 저장할 때 새 비밀번호를 입력하라는 창을 보게 됩니다.

### 3) 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙️) → 웹 앱**을 고릅니다.
2. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정하고 **배포**를 누릅니다.
3. 권한 승인 창이 뜨면 본인 계정으로 승인합니다("확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누릅니다).
4. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

### 4) 앱에 URL 연결
[`config.js`](config.js)의 `apiUrl`에 복사한 URL을 넣습니다.
```js
window.SCHEDULE_BOARD_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec',
  pollIntervalMs: 20000
};
```
`apiUrl`이 비어 있으면 지금처럼 **로컬 모드**(이 브라우저에만 저장)로 동작합니다.

### 5) GitHub Pages로 링크 만들기
1. GitHub에서 `schedule-board` 저장소를 만들고 코드를 올립니다.
   ```bash
   git remote add origin https://github.com/당신의계정/schedule-board.git
   git push -u origin main
   ```
2. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**를 누릅니다.
3. 1~2분 뒤 생성되는 `https://당신의계정.github.io/schedule-board/` 링크를 학생들에게 공유합니다.

### ✅ 설정 확인 체크리스트
- [ ] 화면 왼쪽 위 배지가 **🟢 공유 모드**로 표시된다.
- [ ] 처음 일정을 추가하면 비밀번호 창이 뜨고, 맞는 비밀번호를 넣으면 저장된다(틀리면 다시 묻는다).
- [ ] 다른 브라우저나 휴대폰에서 같은 링크를 열면 약 20초 안에 같은 일정이 보인다.
- [ ] 구글 시트에 `schedules`, `assignees` 탭이 생기고 데이터가 쌓인다.

### 공유 모드 사용 팁
* 다른 사람의 변경 사항은 20초마다, 그리고 탭으로 돌아올 때 자동으로 반영됩니다.
* 여러 명이 동시에 저장해도 서버가 순서대로 처리하므로 서로 덮어쓰지 않습니다.
* 공유 모드에서 **🗑️ 공유 데이터 초기화**를 누르면 모든 학생의 일정이 지워집니다. 먼저 **📤 일정 내보내기**로 백업하세요. 구글 시트의 **파일 → 버전 기록**으로도 복구할 수 있습니다.
* 링크와 함께 비밀번호가 외부로 퍼졌다면 `EDIT_PASSWORD`를 바꾸면 됩니다.
